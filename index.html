接口兼容性与测速说明

三网节点来自公开的测速节点清单，属于候选接口，并非全国统一官方 API。可用性受地区、节点开放策略、HTTPS 证书、端口和跨域许可影响；本页会在测速前检测。检测失败时请换节点或填写你自己的兼容接口，不会跳转页面或替换成其他服务的结果。

Cloudflare 为自动路由，不能保证连接至境外机房。LibreSpeed 的城市来自其公开节点清单。本页始终从当前浏览器直接请求目标节点，不经过本网站服务器中转；启用代理时结果包含代理路径。

结果采用实际字节数与请求耗时估算，属于轻量单连接 HTTP 测试，不代表线路峰值。HTTP 延迟包含连接和服务端处理时间，非 ICMP Ping。Mbps 除以 8 可近似换算为 MB/s。建议暂停其他下载和视频。

自定义接口须支持 HTTPS 和跨域访问。LibreSpeed 填写含 garbage.php 与 empty.php 的 backend 目录；Ookla HTTP 填写含 latency.txt、upload.php、random1000x1000.jpg 等文件的 speedtest 目录。仅能下载时可填写一个随机数据文件的完整地址，上传指标将显示不支持。
